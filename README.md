# goodbye-haejin

슬로우베드 혜진님(Haejin Choi) 송별 롤링페이퍼. 화면은 `public/index.html` 한 장이고, 카드는 `/api/notes` 로 `APP_DATA_DIR/notes.json` 에 저장된다.

- 원본 화면: dbt-workspace `10-projects/2026-10-혜진님-송별-롤링페이퍼/rollingpaper.html` (고친 뒤 여기로 복사)
- 카드 수정·삭제: 처음 쓴 브라우저(수정 열쇠)만. 다른 사람 카드 삭제는 하단 "관리자" 비밀번호
- 로컬 실행: `npm install && npm run dev`
